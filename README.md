## 🧪 Using the Dashboard

The interface provides several controls to manage your search analysis:

- Project Directory: Choose the folder containing your search logs.
- Scan Button: Click this to begin the analysis.
- Report View: Review the findings once the scan ends.
- Export Data: Save your reports as a text file for future reference.

The tool works by comparing search queries against results. It flags instances where the system claims success despite returning unrelated content. This process runs in the background to prevent slowing down your computer.

## 📋 Interpreting Results

The results screen displays a list of search actions. Each entry contains a status label. 

- Green Label: The system matched the query to the correct content.
- Yellow Label: The system found results but with low confidence scores.
- Red Label: The system experienced a silent failure where the search returned erroneous content without warning.

Click on any line item to see details. The details view shows the original query, the result returned, and the explanation for the error.

## 🔧 Frequently Asked Questions

What should I do if the software freezes?
Restart the application from the Start menu. If the problem persists, close other programs to free up memory.

How do I update the tool?
The software checks for updates when you start it. Follow the instructions if a new version appears.

Does the tool send my data to the internet?
No. All analysis stays on your local computer to protect your privacy.

Can I run multiple scans at the same time?
The software performs one scan at a time to maintain system stability. Wait for the current scan to finish before you start another.

What if my search logs contain thousands of files?
The tool processes large batches efficiently. You might notice longer wait times if your storage drive is nearly full.
